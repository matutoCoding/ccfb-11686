# 船行波仿真实验室（Ship Wake Lab）

浏览器内运行的船模拖曳水池船行波仿真与分析系统。TypeScript + WebGPU（WGSL），
无需后端、无需安装插件，数据全部保存在浏览器本地。

## 功能与页面对应

| 页面 | 能力 |
| --- | --- |
| 方案列表 | 一个方案绑定一条参数化船型，挂载多组水池试验工况；显示各工况船速/水深/弗劳德数/实测回填状态 |
| 船型编辑 | 主尺度（Lpp/B/T/Cb/Cm）+ 型线参数（进流角、U/V 倾向、球鼻艏、方艉）实时重建，侧视/俯视/横剖三视图 + 排水体积/Cb 核算 |
| 工况设置 | 船速、水深自动计算 Fr_L、Fr_h；等效移动高斯压力源参数；理论尾迹半角；实测波高 CSV 回填/手动录入 |
| 水面仿真 | 512² 高度场 GPU 谱方法实时仿真，船体移动压力源；菲涅尔反射折射 + 白浪泡沫渲染；轨道相机；水印截图；快照存 IndexedDB |
| 波形分析 | 快照沿船长纵剖面（仿真 vs 实测叠合）、谱域开尔文尾迹半角测量、有限水深理论曲线、CSV 导出 |
| 设置 | 网格分辨率（128–1024）、域长、CFL、消波层、渲染开关；WebGPU 自检与性能基准 |

## 数值方法（核心）

- **时间积分**：自由表面谱方法。线性化方程 η̇=Kφ、φ̇=−gη−gP̂（K=k·tanh(kh)），
  每模式用 2×2 谐振子解析解（cos/sin 算子）推进，无条件稳定、无频散误差。
- **色散关系**：ω² = gk·tanh(kh)，天然包含有限水深效应；深水自动退化为 ω²=gk。
- **FFT**：自研 GPU 二维复数 FFT（位序反转 + 原地 Cooley–Tukey 蝶形，uniform 缓冲池复用）。
- **压力源**：随船移动高斯压力斑，谱解析式含 e^{−i(k·X)} 移动相位与正确的 DFT 归一化 (N/L)²。
- **消波层**：边界海绵带二次衰减，吸收出射波避免周期回卷。
- **尾迹角理论**：群速度方向矢 U·x̂ + c_g·k̂ 求射线角 ψ(χ)，全 χ 域最大值即尾迹半角；
  深水为 19.471°（arcsin 1/3），Fr_h→1 时展宽趋近 90°。
- **尾迹角测量**：船后远场 Hann 窗 → 去均值 → 二维 DFT → 按波数矢角 χ 分箱 →
  群速度几何映射为射线角 ψ → 去趋势找局地峰。抗近轴横波干扰。

## 运行

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建（dist/）
npm test           # 物理/船型/分析单元测试（Vitest）
```

浏览器要求 Chrome/Edge 113+ 或支持 WebGPU 的 Safari，需开启硬件加速。

## 无头 GPU 自检（CI 参考）

`npm run dev` 后，用带远程调试端口的 Chrome 启动，再跑 CDP 脚本：

```bash
chrome --headless=new --enable-unsafe-webgpu --use-angle=d3d11 \
  --remote-debugging-port=9225 --user-data-dir=<tmp> about:blank
CDP_PORT=9225 node scripts/cdp-selftest.mjs   # 跑 /selftest.html
CDP_PORT=9225 node scripts/smoke-app.mjs       # 六个页面冒烟
```

## 验收指标实测（RTX 3060，D3D11 后端，无头）

- 深水尾迹半角：256² 网格测得 18.50°（偏差 0.97°）；512² 测得 18.75°（偏差 0.72°），均满足 <1°。
- 性能：512² 网格纯计算约 430–980 FPS、含渲染约 165 FPS，满足 ≥30 FPS。
- 浅水展宽：理论函数单元测试覆盖，Fr_h 0.08→0.82 尾迹角 19.47°→26°→近临界 64°。

## 数据存储

- 方案/船型/工况/实测：localStorage。
- 高度场快照（含船位元数据）：IndexedDB，供分析页离线测量。
- 截图与 CSV：通过浏览器下载，不上传任何服务器。

## 目录结构

```

src/ui/     六个页面、Canvas 2D 三视图与折线图、路由
scripts/    CDP 无头验证脚本
test/       Vitest 单元测试
```
