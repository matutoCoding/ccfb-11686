# 船行波仿真与水面渲染系统

浏览器端船模拖曳水池辅助系统: 在试验前预览不同船速下的兴波与尾迹形态,
减少水池档期占用。TypeScript + WebGPU 实现, 无重型框架依赖。

## 快速开始

```bash
npm install
npm run dev      # 开发服务器
npm test         # 物理内核验证 (11 项)
npm run build    # 类型检查 + 生产构建
```

浏览器要求: Chrome/Edge 113+ 或 Safari 18+(需硬件加速)。
无 WebGPU 环境自动降级到 CPU 高度场 + 2D 伪彩回退模式。

## 六个页面

| 页面 | 功能 |
|------|------|
| 方案列表 | 船型方案管理; 同一船型挂多组水池试验工况, 展示 Fr/Fh/流态 |
| 船型编辑 | 主尺度(Lpp/B/T)与型线系数(Cb/Cm/Cwp/LCB 等)参数化生成, 侧视/俯视/横剖三视图 |
| 工况设置 | 船速、水深、移动压力源; 自动计算长度/水深弗劳德数; 实测波高 CSV 回填 |
| 水面仿真 | WebGPU 高度场波动方程, 船体等效移动高斯压力源; 菲涅尔反射折射、白浪泡沫、轨道相机 |
| 波形分析 | 沿船长波高剖面, 仿真与实测叠加对比; 尾迹半角能量法测量; CSV 导出 |
| 设置 | 网格/谱分量/阻尼/泡沫阈值等; 项目 JSON 导入导出 |

## 核心物理指标

- **深水尾迹半角**: 开尔文理论 cusp 角 19.471°(asin 1/3);
  谱合成远场能量主峰实测 **20.4°, 偏差 < 1°**(测试 8 强制校验)。
- **浅水效应**: 尾迹角随水深弗劳德数 Fh 增大而张开(Fh≈0.6 实测约 25°),
  Fh→1 趋于完全张开; 超临界 Fh>1 有效波向角自动截断。
- **色散关系**: 有限水深 ω²=gk·tanh(kh), 对单调 F(k) 二分求根, 残差机器精度。
- **性能**: 512×512 高度场每帧 2 计算子步; 无独显时 CPU 回退降档 256 网格,
  实测稳定 60 FPS。

## 架构

```
src/
  core/           纯函数物理内核(无 DOM/GPU 依赖, 可独立 node 测试)
    physics.ts    弗劳德数、色散关系、波数求解、群速比
    kelvin.ts     移动压力源谱合成、波面采样、尾迹角能量法测量
    hull.ts       船型参数化几何、横剖面/水线、压力源等效参数
    types.ts      数据模型与持久化结构
  gpu/            WebGPU 计算与渲染
    simShader.ts    高度场波动方程 WGSL(压力源+阻尼层)
    waterSim.ts     计算管线/乒乓缓冲/高度读回
    renderShader.ts 菲涅尔+折射+白浪 WGSL
    waterRenderer.ts 轨道相机/索引网格/主循环
    cpuSim.ts / cpuRenderer.ts  无 GPU 回退
  ui/pages/       六个页面
  state/store.ts  响应式 store + localStorage
tests/            node:test 物理验证
```

## 模型边界

线性势流远场模型, 不含破波、粘性与船体非线性;
近场伯努利凹陷以经验比例叠加。定位为试验前方案筛选与趋势预判,
不替代 CFD 或实物水池的定量阻力/耐波结论。实测数据通过 CSV
(两列: 纵向位置 x m、波高 z m)回填后与仿真剖面叠加查看偏差。
