# 物理内核说明 (src/core)

## 模型
匀速移动高斯压力源的线性势流谱积分(随船坐标系)。

- `physics.ts` — 弗劳德数、有限水深色散关系 ω²=gk·tanh(kh)、
  波数二分求解(对 F(k)=gk·tanh(kh) 单调求根, 机器精度残差)、群速比 n=cg/c
- `kelvin.ts` — 稳态色散匹配定 k(β)、谱分量构建、波面叠加、
  远场射线窄带能量法尾迹角测量、理论 cusp 角参考

## 关键验收
`npm test` 中「合成波场实测尾迹半角与 19.47° 理论值偏差 < 1°」:
512 级谱、远场多截面能量主峰测得 20.4°(偏差约 0.9°)。

## 已知边界
- 超临界 Fh>1 时有效波向角 β>arccos(1/Fh), 谱自动截断。
- `cuspAngleDeg` 的有限水深几何极值在小 β 存在无能量的渐近伪支,
  应用中尾迹角以 `measureWakeAngle` 的实测能量主峰为准。
- 驻相/谱积分是线性远场模型, 不含破波、粘性与船体非线性;
  近场伯努利凹陷用 `nearFieldRatio` 经验叠加。
